Entry 002 · March 2026 · Infrastructure

building the workspace

Before you can run a serious RC prep cycle, the infrastructure needs to work. This entry covers the work we did this week to get everything organized — the site, the Team Resolve workspace, and the MTG Meta Analyzer — so that the actual competitive work has a solid foundation under it.

Not glamorous. But it matters. Disorganized prep is a tax on every decision you make during a season.

what got built

Website
Full Content Rewrite
Every page rewritten with accurate content — Modern focus, current results (23+17 RCQ Top 8s, 5 RC qualifications), Team Resolve philosophy, and actual decks being tested. The old site had Pioneer meta data from 2024. Now it reflects what we're actually doing.
Website
Design System
Rebuilt styles.css with CSS variables, DM Mono font, card grid layouts, expandable detail sections, and the blink guide design patterns applied throughout. Consistent across all pages now.
Team Resolve
Workspace Organized
95 files moved from a flat root folder into organized subfolders: guides/, data/, prep/, media/, decks/, tools/. CLAUDE.md workspace map written. Each folder has a context.md explaining what belongs there and the naming convention.
MTG Meta Analyzer
User Preferences Wired
Format selection now lives in preferences.json and drives all scrapers. The setup wizard has a format selection page before Scryfall download. background_fill.bat reads preferences instead of hardcoded format lists. Documentation updated across CLAUDE.md, NEXT_STEPS.md, and ROADMAP.md.

why this matters for the rc grind

The MTG Meta Analyzer is a core part of how Team Resolve prepares. It pulls real match data from melee.gg — 262,000+ match records across formats — and surfaces which archetypes are actually winning, not just which ones are popular. The Field Optimizer runs the expected field composition through win rate data to tell us which deck has the best weighted win percentage against what we'll face at the RC.

That tool only works if it's actually running. Organizing the infrastructure — getting the daily scrapes working reliably, preferences wired correctly, documentation accurate — is what makes it usable across a long season. A tool you have to babysit every week is a tool you'll stop using.

"Preparation infrastructure is as important as the preparation itself. If your systems are broken, your prep is broken."

current testing status

The gauntlet work continues in parallel. UW Blink is still the primary focus. Here's where each deck stands:

  • UW Blink: Most reps. Feeling strong against the midrange half of the field. The Prowess matchup is the main concern — they can close before Ephemerate comes online if you keep a medium hand.
  • Boros Energy: Monitoring the hate density. Sanctifier en-Vec is now in a lot of sideboards. Still powerful but the margins are tighter than last season.
  • Grixis Reanimator (Glockulous): Had two strong gauntlet runs. The melee.gg data shows the field is not heavily prepared with dedicated graveyard hate for this specific season — which is the key read we needed.
  • Jeskai Blink: Still evaluating. The mana hit is real. We'll make the call based on how much combo shows up in the expected RC field.
  • UW Control / Prowess: Both monitoring. Neither is the primary right now.

next steps

  • Continue gauntlet reps — need more data on UW Blink vs Prowess specifically
  • Pull current MTGMelee data on graveyard hate density in recent Modern RCQs
  • Make deck decision and build the full sideboard guide before the next event block
